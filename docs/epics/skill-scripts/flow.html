How a Skill script works

An author ships a tested calculation inside a Skill. Eneo keeps it unchanged and runs it in a sealed box. The model only asks for it.

1. Author uploadsA ZIP with SKILL.md and one or more scripts. Needs the permission Manage Skill scripts.
2. Eneo checks and storesThe runtime compiles each script without running it. The package becomes an immutable revision.
3. Publisher approvesDownloads the exact package, reviews it, publishes one revision. Logged in the audit log.
4. The model asks for itIn a chat it names the script and gives JSON input. It can never send code.
5. Eneo decidesMay this user run it? Is there budget left this turn? Yes: write a record, then run.
6. The sealed box runs itFresh process, no network, no files, 5 seconds, 64 MB. Same box that runs model-written JavaScript today.
7. Answer and traceThe result is saved before the model answers. The debug panel shows what ran, how long, and the outcome.

Instruction-only Skills do not change. A Skill without scripts never touches the runtime.
