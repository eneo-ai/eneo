# Epic #660 diagrams: Skills with scripts

Pictures used in epic eneo-ai/eneo#660 "Skills can include tested calculation
scripts that run in Eneo's isolated runtime".

- `skill-scripts-layers.png`: five layers, from the person to the kernel
- `skill-scripts-flow.png`: how a Skill script works, from upload to answer
- `skill-scripts-roles.png`: who does what, and who sets which limit
- `skill-scripts-example.png`: worked example with a day-by-day scale

Each PNG is a screenshot of the HTML file with the same name. To regenerate:
open the HTML file in a browser at 1640 px width (the page uses `zoom: 2` for
a crisp 1600 px image) and screenshot the `.page` element.
