The downloadable `eneo-word-template.docx` is a byte-for-byte copy of
`backend/src/eneo/flows/runtime/templates/standard/dokument.docx`.
It contains one body-level rich text content control, tagged `dokument`, and uses
Word's standard styles. The template editor offers it as an editable example.

The source template is generated by
`backend/scripts/build_standard_docx_templates.py`. When updating the example,
copy the reviewed source file and verify inspection through the template upload
API. The browser regression test uploads this shipped file and maps its control.
