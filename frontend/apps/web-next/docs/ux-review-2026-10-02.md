# UX review, 2 October 2026

Full report with screenshots: https://claude.ai/artifact/Ws3H9Hy3g1MjnJHQm6bsnu
(private artifact; share from its page). Reviewed on feat/web-next-astryx at
73ff8f03b: start, chat, spaces, knowledge, assistant editor, account and every
admin page, light and dark, desktop and 375 px. Chat ran against the e2e stack
(mock model); everything else against the dev backend.

Tick items off here or move them to GitHub findings; keep the ids so the
screenshots in the report stay linked.

## A. Bugs

- [ ] A1 Chat shows raw backend JSON as the error text. Map codes to copy, keep details behind "Visa detaljer".
- [ ] A2 `governance-policy-page.tsx` runs `useSuspenseQuery` during SSR with the relative proxy URL and errors on every render; prefetch server-side or render on the client.
- [ ] A3 Lists that fail (audit logs, roles, skills) show skeletons or "Laddar…" forever. Shared error state with retry.
- [ ] A4 Account: language selector shows no selected value.
- [ ] A5 Space overview "Om ytan": "Skapad" without a value, raw model ids instead of display names.
- [ ] A6 Verify: provider card masks the key as "…Yg==", which looks like the ciphertext, not the key.

## B. Unnecessary steps / simplify

- [ ] B1 Create assistant: drop the name dialog, open the editor with "Ny assistent" prefilled and focused.
- [ ] B2 What's new modal blocks the first screen after login; prefer a badge in the account menu plus a one-time banner.
- [ ] B3 Three places list recent conversations (sidebar, history panel, ⌘K); make the sidebar primary.
- [ ] B4 Context meter under the composer is always visible; show from ~60 % or behind the tools menu.
- [ ] B5 Admin landing is four feature toggles; make it an overview and move toggles to settings.
- [ ] B6 Admin menu has 18 items; merge Verktyg/MCP-servrar/Moduler/Integrationer, move Skills under Styrning.
- [ ] B7 Assistant editor stacks space header, space tabs, breadcrumb and section tabs; last tab clips at 1440 px. Let the editor own the surface.
- [ ] B8 Audit logs: five filter controls and an unlabelled retention box; filter button with chips, retention to settings.

## C. Clarity and language

- [ ] C1 The personal assistant is called "Default" in the chat header, mobile header and the composer's accessible name; ⌘K says "Personlig assistent". Use the latter everywhere.
- [ ] C2 English leftovers: "Organization space", template category "communication", "Completion-modell".
- [ ] C3 Login lockout copy wraps the count onto its own line ("…tillfälligt: 4"). Write "4 försök kvar …" as its own line.
- [ ] C4 Model lists mix display names and ids ("Claude Haiku 4.5" vs "claude-haiku-4-5").
- [ ] C5 Three loading patterns (text, skeleton, nothing); standardise on Astryx LoadingState/skeleton.

## D. Visual and playfulness

- [ ] D1 Admin crawler empty state is dashes and empty rows; design a real empty state.
- [ ] D2 MCP "Väntar på granskning 0" uses the warning colour at zero.
- [ ] D3 Answers render in Source Serif 4 while everything else is Figtree; decide deliberately, test with users.
- [ ] D4 Mobile space tabs scroll without an edge fade or wrap.
- [ ] D5 Playfulness lives only on the start page's suggestion cards; reuse the coloured icon tiles in empty states and admin cards, animate "Alla ändringar sparade".

## Not reviewed

Chat with tools, approvals, sources and attachments; knowledge with data and
the crawler UI with runs; apps, group chats, services, integrations; the manual
accessibility protocol. Needs a backend with the merged code and a real model key.
