# Documentation

This is the technical map of Eneo. Use the linked owner documents and the running
application's OpenAPI schema for details that change with a release.

## Start here

- [Getting Started](/docs/getting-started) explains local setup and the first
  configuration steps.
- [Deploy Eneo](/guides/deployment) describes the reference production
  deployment, operational configuration, and supported infrastructure choices.
- [Architecture](/docs/architecture) explains the deployed components and their
  responsibilities.
- [API Reference](/docs/api) points to the generated API contract and interactive
  explorer.

## Product and operational references

- [Eneo Flows](/docs/flows) and [Flows for Developers](/docs/flows-for-developers)
  describe Flow authoring and runtime contracts.
- [Knowledge Retrieval and MCP Interoperability](/docs/knowledge-retrieval-and-mcp)
  explains injected retrieval, built-in MCP servers, and external tool boundaries.
- [Object Content Architecture](/docs/object-content-architecture) describes
  durable file-byte storage, integrity, retention, and recovery.
- [Audit Logging](/docs/audit-logging) describes compliance-relevant event
  recording and retention.
- [API Key Management](/docs/api-key-management) explains API-key lifecycle and
  access scope.
- [Release SBOMs](/docs/release-sboms) explains released-image provenance and
  software-bill-of-material artifacts.

## Identity and access

- [Multi-Tenant OIDC Federation](/guides/oidc-federation/multi-tenant) explains
  tenant-specific identity-provider configuration.
- [Authentication Architecture](/docs/authentication-architecture) is the
  maintainer-facing reference for the OIDC implementation.
- [SCIM Provisioning](/guides/scim-provisioning) covers user provisioning when
  an identity provider supports it.

## Contributing

- [Contributing](/contributing) explains repository contribution paths.
- [Security for Contributors](/contributing/security) explains how to report and
  handle security issues.
- The [GitHub repository](https://github.com/eneo-ai/eneo) is the source for
  release history and issues.
