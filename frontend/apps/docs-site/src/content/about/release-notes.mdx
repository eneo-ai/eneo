# Release notes

What has changed for the people who use Eneo, newest release first. The same
notes appear inside the app under **What's new** in the account menu. Notes
for developers and operators — dependency bumps, migrations, deployment
changes — live in the [GitHub releases](https://github.com/eneo-ai/eneo/releases).

In the standard Eneo app, each release candidate announces its news once per
user: seeing RC0 does not dismiss RC1 or the final release. Candidates share
the release's notes rather than adding duplicate entries here. Opening the
What's new page marks that installed version as read; dismissing the popup
alone does not mark it as read.

In the app, **What's new** shares the account sidebar with **My account**,
**Integrations** and **API keys**. Select **What's new** there to browse releases;
the notes use the available width beside the sidebar. On smaller screens, open
the **Account and settings** menu button to switch between these pages.
