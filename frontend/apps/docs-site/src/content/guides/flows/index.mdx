# Eneo Flows for API consumers

This section is for teams that use Eneo Flows inside their own service or web app, and it helps you choose the right guide before you design, run, or troubleshoot a flow.

You are at the start of the consumer journey: design the flow, integrate the runtime calls, then use the FAQ and reference when questions come up.
