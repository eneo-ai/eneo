# Eneo Flows for API consumers

This section is for teams that run published Eneo flows from their own
service or application. Flows themselves are written by people in Eneo;
nothing here asks you to author one.

| Page                                                 | Use it for                                                              |
| ---------------------------------------------------- | ----------------------------------------------------------------------- |
| [Integrating Flows](/guides/flows/integrating-flows) | The runtime workflow: discover, upload, create, poll, review, download. |
| [Error reference](/guides/flows/reference/errors)    | The machine-readable error codes and what to do with them.              |

The live contract of the deployment you target is served from its origin
at `/openapi.json`, with interactive documentation at `/docs`. When a page
and the deployment disagree, the deployment is right.
